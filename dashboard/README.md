# Security Dashboard

Hosts the Security Operations Center (SOC) dashboard.
- Aesthetic: Monochrome (White / Black / Slate Grey)
- Key Views:
  1. Overview (Current vs Future Risk, Early Warning Alert)
  2. Network State Analysis (1-min aggregated metrics)
  3. Future Forecast (K-step rollout timeline)
  4. MITRE ATT&CK Mapping (Stage progression)
  5. Explainability (Feature attributions & SHAP values)
